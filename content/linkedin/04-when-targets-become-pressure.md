## FULL LINKEDIN POST

WHEN TARGETS BECOME PRESSURE

Following on from "The Target Question" — here is *how* PostalMind actually tells the difference,
using an illustrative, synthetic example (no real names, no real messages).

Day 1: a target is set for the month. Routine.
Day 15: a mid-month review flags a shortfall. Routine.
Day 20: a message asks for an update, during working hours. Still routine.
Day 24, 25, 26: the same demand repeats daily, now after working hours, now in a group where other
staff can see the individual's numbers.
Day 27: a message links the shortfall to an upcoming leave request.

Read in isolation, day 20's message looks identical to day 1's. Read as a sequence — frequency,
timing, audience, and what got linked to what — a pattern becomes visible that a single message never
would show. That is the entire reason PostalMind's evidence tool builds a timeline (PRE / EVENT / POST)
instead of scoring one message in isolation.

None of this means every target follow-up is pressure. Most aren't. It means the honest answer to
"was this pressure?" is almost never in one message — it's in the pattern, the timing, and whether the
same demand starts touching things unrelated to the target itself, like leave or a threatened
inspection.

This is also why PostalMind will not publish a "harassment score." A number invites exactly the kind of
overclaim this project is built to resist. What it will publish, once a real case is documented and
passes its safety and counter-evidence checks, is the sequence itself — dated, sourced, with the
Department's response included if one exists — and let a reader judge it against the same indicators
named in the previous post.

This is not a campaign against individual postal employees.

It is a campaign to document the system.

Ground reality. Verified.

## SHORT VERSION
The same message, once, is a review. The same message, repeated after hours, escalating to a group
channel, then linked to a leave request — is a different evidence picture. PostalMind's evidence tool
builds a timeline, not a single-message score, because pattern (frequency, timing, audience, what gets
linked to what) is what actually distinguishes review from pressure. No harassment score — a dated,
sourced sequence instead, illustrated here with a synthetic example only. Ground reality. Verified.
